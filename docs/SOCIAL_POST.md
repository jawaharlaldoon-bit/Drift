We built Drift for the Taskmaster track: an event-driven AI incident responder that turns
a failed agent workflow into a GitHub issue, constrained fix, live replay evidence, draft
pull request, and Slack handoff—while keeping merge authority with a human.

Built with Gemini 3.5 Flash, Google ADK, Cloud Run, Pub/Sub, and Firestore.
